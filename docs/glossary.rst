Glossary
========

Add data
   Study-level permission to create or update data-entry records.

BIDS
   Brain Imaging Data Structure, a convention for organizing supported
   neuroimaging and related research data.

CRF / eCRF
   Case report form / electronic case report form.

Draft
   Editable pre-publication study state that is not used for routine data
   collection.

Field identifier
   Stable machine-oriented name used to store and export a field.

Form slot
   The form-entry context for a subject and visit.

Group
   A study-defined arm, cohort, site, or other subject partition.

Protocol matrix
   Mapping of form sections to visits and study groups.

Published
   Active study state available for data collection.

Revision token
   Version marker used to detect that an entry changed after a user opened it.

RIA store
   Storage layout used with DataLad-backed datasets in hosted operation.

Section template
   Reusable saved form-design section; not a partial data-entry save.

Shared link
   Time- and scope-limited URL that permits configured view or add-data activity
   without ordinary recurring study access.

Skipped required value
   A required field deliberately recorded as unavailable through the supported
   skip workflow, rather than left silently blank.

Study owner
   User responsible for a study with owner-level management capabilities.

Visit
   Protocol-defined collection time point or event.
